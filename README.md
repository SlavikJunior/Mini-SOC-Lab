# Mini SOC Lab

Учебный мини-проект для практики обнаружения и первичного расследования подозрительных событий Windows и сетевой активности.

> **Важно:** все события в `logs/sample_events.jsonl` синтетические. Это демонстрационный набор данных, а не реальные журналы организации. Проект не подключается к SIEM и не выполняет мониторинг в реальном времени.

## Цели

- разобрать несколько синтетических событий Windows/Sysmon;
- продемонстрировать Sigma-правила для неудачных входов и подозрительного запуска процесса;
- проверить простые детекторы на тестовых данных;
- описать учебный сценарий расследования и рекомендации;
- зафиксировать ограничения детектирования и возможные ложные срабатывания.

## Требования

- Python 3.10+
- `pytest` для запуска тестов (необязательно для самого анализатора)

Установка pytest:

```bash
python -m pip install pytest
```

## Быстрый запуск

Из корня репозитория:

```bash
python scripts/analyze_events.py
python -m pytest -q
```

Для вывода JSON-отчёта в файл:

```bash
python scripts/analyze_events.py --output analysis/generated-report.json
```

Анализатор использует прозрачные эвристики для **учебного JSONL-формата**. Это не полноценный парсер EVTX, не движок Sigma и не замена SIEM. Sigma-правила в репозитории представлены отдельно и требуют адаптации к конкретному источнику логов и схеме полей.

## Что проверяет анализатор

1. Считает события неудачного входа (`EventID 4625`).
2. Выделяет IP-адреса, от которых зарегистрировано не менее трёх неудачных входов.
3. Помечает события создания процессов (`Sysmon EventID 1`) с демонстрационными подозрительными именами процессов/командных строк.
4. Формирует список наблюдений с временем, источником события и обоснованием.

Порог в три неудачных входа выбран только для демонстрации и не является универсальным правилом обнаружения brute force.

## Интерпретация результатов

Срабатывание — это повод для проверки, а не доказательство компрометации. Проверяйте контекст: тип учётной записи, ожидаемые административные действия, родительский процесс, подпись/путь файла, исходный IP, временную шкалу и связанные события.

## Безопасность и воспроизводимость

- Данные синтетические; вредоносные файлы и реальные учётные данные не используются.
- В проекте нет эксплуатации уязвимостей, сканирования внешних адресов или запуска вредоносного ПО.
- Для сетевой части предусмотрено место для описания анализа легально полученного учебного PCAP; сам PCAP не включён, чтобы не выдавать синтетический файл за реальный захват.

## Возможные улучшения

- добавить парсер EVTX на базе проверенной библиотеки;
- проверять Sigma-правила через `sigma-cli`/pySigma и целевой backend;
- добавить нормализацию полей и тесты на ложноположительные результаты;
- подключить учебный Wazuh/Elastic стенд и документировать настройку;
- анализировать предоставленный учебный PCAP в Wireshark и сохранять фильтры/наблюдения.
