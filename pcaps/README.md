# PCAP analysis exercise

В репозитории намеренно нет PCAP-файла: не следует представлять синтетический или скачанный без проверки трафик как собственный захват.

## Практическое задание

1. Возьми PCAP из разрешённого учебного источника (например, официального набора учебных трасс Wireshark) или создай собственный захват в локальной лаборатории.
2. В Wireshark проверь:
   - `dns` — DNS-запросы и ответы;
   - `tcp.flags.syn == 1 && tcp.flags.ack == 0` — начальные TCP SYN;
   - `ip.addr == <адрес>` — трафик выбранного узла.
3. Запиши время, источник и назначение, протокол, наблюдение и альтернативные объяснения.
4. Не делай вывод о компрометации только на основании необычного порта или одного DNS-запроса.

Добавь свои заметки в `analysis/incident-report.md`, укажи источник PCAP и контрольную сумму файла.
